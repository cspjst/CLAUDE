# Washup — leaving a chat so the next one can pick up from the oracle

*Owned by synergy's WELFARE. First done 2026-10-29 19:30–19:50, at Jeremy's request: "perform a washup procedure ... so that I can leave this chat where it is an return at some point in the future and you will be able to start it up again from ~/synergy". Its complement is `wakeup.md`. Every department washes up; only WELFARE pushes.*

## When
- Before leaving a chat for a while, before a planned compaction, or when the human says "washup".
- Not as a substitute for writing things down as they happen (principle 1) — a washup catches what slipped through.

## The steps
1. **Welfare first.** Is it a sensible hour; has the human eaten? A washup can wait for dinner.
2. **Check access.** The oracle folder, and delete permission there (create and remove a scratch file under `.git`); the keys folder if this department signs. Ask again if any has lapsed.
3. **Commit your own work** — signed, if this department signs. Stage named paths only. Leave other departments' and the human's uncommitted work alone; mention it.
4. **Write the history.** Extend `<REPO>-historiography.md` with everything since its last chapter, while the chat still remembers it: the problem, what was tried, what the sources said, what was decided — the human's words quoted and timed, thin stretches labelled. *(WELFARE; other departments send theirs to WELFARE in the dialogue.)*
5. **Bring the working agreement up to date.** Its Status and "Open — <HUMAN>'s calls" sections, so a fresh session can trust them. *(Departments: their notes' Current state and Open.)*
6. **Lessons into the operating model** — anything general this chat learned; and into `wakeup.md` anything that changes how a session starts.
7. **Tidy the dialogue.** Close your open entries, or say why they stay open.
8. **Write the washup handover:** `handover/<date>-<dept>-washup.md` — where things stand, what's waiting on whom, anything `wakeup.md` doesn't already say. Short: the documents carry the detail.
9. **Push** — WELFARE only, on the human's word (*proposal, not yet <HUMAN>'s call: asking for a washup counts as that word*). Fetch first: if GitHub has commits the oracle hasn't (the human's from another machine, a collaborator's merged pull request), bring them in before pushing. Record the push in the dialogue with the hash. Other departments ask WELFARE in the dialogue.
10. **Refresh the project's copies**, at the paths its Instructions use.
11. **Verify.** Read every write back; the oracle, GitHub and the project agree; signed commits verify.
12. **Tell the human** the one line that starts the next session, e.g. *"WELFARE. Read wakeup.md in ~/synergy and follow it."*
